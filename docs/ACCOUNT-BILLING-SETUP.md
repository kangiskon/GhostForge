# GhostForge v0.4 — Accounts, Families and Google Play subscriptions

## What ships in the beta
- Sign-in uses a **verified email address**, six-digit email code and a short-lived bearer session.
- Devices are registered under that verified identity using an app-generated random UUID, **not** Android hardware ID, IMEI, phone number or another identifier. Each account can register six.
- Household group membership requires a verified email address and a one-time invitation generated by the household owner. Each group is limited to five; invitations expire in one hour. Household enrollment alone does **not** grant paid subscription entitlements.
- Account deletion removes the user's sessions, invites, device and family membership records. Owners deleting their accounts disband their household. **Deleting an account does not cancel a subscription with Google Play.**
- Scan history is AES-GCM encrypted at rest on the user's device. Only normalized hostname, verdict and timestamp are saved. Full URLs, query strings, scanned APK files and scam message contents are not saved there.
- The app queries Google Play subscription products, can display offers, start Google Play checkout, restore purchases, and submits purchase tokens to the backend. **It never enables premium on the basis of local purchase state alone.** Only positive Google Play Developer API verification sets an entitlement.

## Server setup
Run a trusted TLS reverse proxy in front of the existing FastAPI backend; Docker binds to localhost by default.

In **server-only secrets**, configure:
- GHOSTFORGE_AUTH_SECRET: a freshly generated random secret at least 32 characters long, persisted across backend restarts.
- SMTP_HOST, SMTP_PORT, SMTP_FROM, SMTP_USER, SMTP_PASSWORD: dedicated SMTP credentials. Email verification will fail closed until configured.
- HIBP_API_KEY, WEB_RISK_API_KEY, OPENAI_API_KEY: optional licensed reputation feeds and AI analysis.
- GHOSTFORGE_PLAY_PRODUCTS: comma-separated product IDs actually created for your app in Google Play Console, such as ghostforge_premium_monthly,ghostforge_family_monthly.
- GHOSTFORGE_PLAY_BILLING_ENABLED: **false** by default. Set to true only after verified backend credentials, privacy review and Play testing.
- GOOGLE_APPLICATION_CREDENTIALS: an absolute **backend-only** location for a restricted Google Play Developer API service-account JSON. Securely mount it read-only into Docker; do not commit it or place it into an Android APK. Grant the account limited access to subscription order lookup in Play Console.

Google Play's API requires package name **com.ghostforge.app** and the androidpublisher OAuth scope. The backend uses subscriptionsv2 to inspect the actual subscription state, listed product ID and expiry. It rejects absent products, expired/unverified tokens and purchase tokens previously linked to another account.

Production follow-ups: Real-time Developer Notifications (RTDN), renewal/refund reconciliation, durable entitlement refresh, server-side purchase acknowledgement where appropriate, fraud monitoring, retention limits, stronger rate limiting/IP throttling, durable job queues, audit logging with content redaction, independent security assessment, backup restoration tests and privacy/data-safety legal review.

## Samsung Tab S9+ build
1. Open GitHub Actions in the GhostForge repository on your tablet.
2. Download the **GhostForge-Debug-APK** artifact of a successful build.
3. Extract and install the debug APK. Debug APKs sideloaded outside Google Play usually cannot sell Google Play subscriptions.
4. Configure a trusted HTTPS GhostForge server in **Settings**. Verify your email in **Breaches** before using **Account** or **Premium**.
5. Test DNS Guard on Wi-Fi and mobile data; stop if browsing breaks.

No API keys, tokens or private server credentials should be pasted into chat or committed to source code. The source repository is currently public.

## Remaining commercial launch requirements
This is a working, testable feature beta, not a finished antivirus or commercially approved security product. Actual Google Play subscription sales require Play Console configuration, proper app signing, release track distribution, account and device testing, consent/privacy documents, customer support, cancellation pathways and policy review. Full malware scanning also needs third-party malware intelligence and independent detection validation.
